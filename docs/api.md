# REST API Reference: EnterpriseHub

- `GET /api/health`: Health status.
- `GET /api/metadata`: Database summary counters.
- `GET /api/schema/table/<name>`: Schema definition & sample rows.
- `GET /api/queries?category=all&difficulty=all`: 100+ Query catalog.
- `POST /api/sql/execute`: SQL Playground execution sandbox with EXPLAIN plan.
- `GET /api/viva/questions`: Viva Q&A catalog.
- `POST /api/transactions/demo`: ACID transaction execution simulator.
